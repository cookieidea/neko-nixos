# niri 快捷键

配置：

```text
configuration/home/dotfiles/config/niri/binds.kdl
```

`Mod` 为 Super/Windows 键。

快捷键教程：`Mod+Shift+/`

## 启动

| 快捷键 | 功能 |
|---|---|
| Mod+Return | Kitty 独立终端 |
| Mod+T | Kitty 共享终端 |
| Mod+/ | 浮动终端 |
| Mod+Alt+O | opencode |
| Mod+B | Chrome |
| Mod+E | Nautilus |
| Mod+Z | Noctalia Launcher，失败时回退 fuzzel |
| Mod+F1 | 重启 fcitx5 |
| Mod+F2 | Noctalia 设置 |
| Mod+O / G | niri Overview |

## 聚焦

| 快捷键 | 功能 |
|---|---|
| Mod+← / H | 左列 |
| Mod+→ / L | 右列 |
| Mod+↑ / K / W | 上窗口 |
| Mod+↓ / J | 下窗口 |
| Mod+Home | 第一列 |
| Mod+End | 最后一列 |
| Alt+Tab / Alt+Shift+Tab | 当前显示器窗口切换 |
| Mod+Tab / Mod+Shift+Tab | 当前工作区窗口切换 |

## 移动

| 快捷键 | 功能 |
|---|---|
| Mod+Ctrl+← / H | 左移列 |
| Mod+Ctrl+→ / L | 右移列 |
| Mod+Ctrl+↑ / K / W | 上移窗口 |
| Mod+Ctrl+↓ / J / S | 下移窗口 |
| Mod+Ctrl+A / D | 左 / 右移动列 |
| Mod+A / D | 左 / 右移动窗口 |
| Mod+[ / ] | 左 / 右移动窗口 |
| Mod+, | 合并到当前列 |
| Mod+. | 移出当前列 |
| Mod+Shift+A / D | 合并 / 移出窗口 |

## 显示器

| 快捷键 | 功能 |
|---|---|
| Mod+Shift+方向键 / HJKL | 聚焦对应显示器 |
| Mod+Shift+Ctrl+方向键 / HJKLAD | 移动列到对应显示器 |
| Mod+Shift+Alt+方向键 / HJKLADWS | 移动整个工作区到对应显示器 |

## 工作区

|---|---|

| Mod+PageUp / PageDown | 上 / 下工作区 |

| Mod+Shift+PageUp / PageDown | 移动工作区 |
| Mod+Shift+U / I | 移动工作区 |
| Mod+Shift+滚轮 | 切换工作区 |
| Mod+Ctrl+Shift+滚轮 | 移动列到工作区 |
| Mod+Ctrl+Home / End | 移动列到首 / 尾位置 |

## 输入法

| 按键 | 功能 |
|---|---|
| Mod+F1 | 重启 fcitx5 |
| Ctrl+Space | fcitx/Rime 切换 |
| Ctrl+Shift+F | 繁简切换 |
| Ctrl+. | 中英文标点 |

Rime 的后两项不属于 niri binding。
