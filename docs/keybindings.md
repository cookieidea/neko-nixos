`# 快捷键

当前桌面为 niri + Noctalia。

`Mod` 指 Super（Windows）键。

快捷键配置主要位于：

```text
configuration/home/dotfiles/config/niri/binds.kdl
```

教程入口：

```text
Mod+Shift+/
```

## 启动与桌面

| 快捷键 | 功能 |
|---|---|
| Mod+Return | Kitty 独立终端 |
| Mod+T | Kitty 共享终端 |
| Mod+/ | 临时浮动终端 |
| Mod+Alt+O | opencode |
| Mod+B | Chrome |
| Mod+E | Nautilus |
| Mod+Z | Noctalia Launcher，失败时回退 fuzzel |
| Mod+F1 | 切换 fcitx5 |
| Mod+F2 | Noctalia 设置 |
| Mod+O | niri 总览 |
| Mod+G | niri 总览 |

## 窗口聚焦

| 快捷键 | 功能 |
|---|---|
| Mod+← / H | 聚焦左列 |
| Mod+→ / L | 聚焦右列 |
| Mod+↑ / K | 聚焦上方窗口 |
| Mod+↓ / J | 聚焦下方窗口 |
| Mod+Home | 第一列 |
| Mod+End | 最后一列 |
| Alt+Tab | 当前显示器窗口切换 |
| Mod+Tab | 当前工作区窗口切换 |

## 窗口移动

| 快捷键 | 功能 |
|---|---|
| Mod+Ctrl+← / H | 向左移动列 |
| Mod+Ctrl+→ / L | 向右移动列 |
| Mod+Ctrl+↑ / K | 向上移动窗口 |
| Mod+Ctrl+↓ / J | 向下移动窗口 |
| Mod+Ctrl+A | 列向左移动 |
| Mod+Ctrl+D | 列向右移动 |
| Mod+A | 窗口移到左侧列 |
| Mod+D | 窗口移到右侧列 |
| Mod+[ | 窗口移到左侧列 |
| Mod+] | 窗口移到右侧列 |
| Mod+, | 合并到当前列 |
| Mod+. | 从当前列移出 |

## 显示器

| 快捷键 | 功能 |
|---|---|
| Mod+Shift+方向键 | 聚焦对应显示器 |
| Mod+Shift+Ctrl+方向键 | 把列移动到对应显示器 |
| Mod+Shift+Alt+方向键 | 把整个工作区移动到对应显示器 |

方向键通常也提供 H/J/K/L/A/D 对应绑定。

## 工作区

| 快捷键 | 功能 |
|---|---|
| Mod+1 … Mod+9 | 切换到对应工作区 |
| Mod+Ctrl+1 … Mod+Ctrl+9 | 把当前列移动到对应工作区 |
| Mod+PageUp / PageDown | 上下工作区 |
| Mod+U / I | 上下工作区 |
| Mod+Shift+PageUp / PageDown | 移动整个工作区 |
| Mod+Shift+U / I | 移动整个工作区 |
| Mod+Shift+滚轮 | 上下切换工作区 |
| Mod+Ctrl+Shift+滚轮 | 移动列到上下工作区 |

## 终端与实用脚本

| 快捷键 | 功能 |
|---|---|
| Mod+F5 | `quicksave` |
| Mod+F8 | `quickload` |
| Mod+P | 获取当前窗口信息 |
| Mod+F10 | 随机壁纸 |
| Mod+Shift+F10 | 随机下载壁纸 |

部分快捷键依赖 `~/.local/bin` 或 `~/.config/niri/scripts` 中的本地脚本。

## 输入法

| 快捷键 | 功能 |
|---|---|
| Mod+F1 | 停止并重新启动 fcitx5 |
| Ctrl+Space | fcitx/Rime 常用切换键 |
| Ctrl+Shift+F | 繁简切换 |
| Ctrl+. | 中英文标点 |

其中后两项来自 Rime 配置，不属于 niri 的窗口绑定。
