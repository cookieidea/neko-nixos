# 快捷键（niri + Noctalia）

`Mod` = Super 键。按 `Mod+Shift+/` 查看内置教程。

## 启动

| 快捷键 | 功能 |
|--------|------|
| Mod+Return | 终端（kitty） |
| Mod+T | 共享终端 |
| Mod+/ | 临时浮动终端 |
| Mod+Alt+O | opencode |
| Mod+B | Chrome |
| Mod+E | 文件管理器 |
| Mod+Z | 程序菜单 |
| Alt+Tab | 窗口切换器 |
| Mod+F1 | 切换输入法 |
| Mod+F2 | 设置面板 |

## 窗口聚焦

| 快捷键 | 功能 |
|--------|------|
| Mod+←/→ 或 H/L | 左右列 |
| Mod+↑/↓ 或 K/J | 上下窗口 |
| Mod+Home/End | 首/末列 |
| Mod+PageUp/PageDown | 上下工作区 |

## 窗口移动 / 尺寸

| 快捷键 | 功能 |
|--------|------|
| Mod+Ctrl+方向键 | 移动列/窗口 |
| Mod+A/D | 跨列移动 |
| Mod+-/= | 列宽 ±5% |
| Mod+Shift+-/= | 窗高 ±5% |
| Mod+F | 最大化列 |
| Mod+Alt+F | 全屏 |
| Mod+V | 切换浮动 |
| Mod+Q | 关闭窗口 |
| Alt+F4 | 强制杀窗口 |

## 工作区

| 快捷键 | 功能 |
|--------|------|
| Mod+1~9 | 切换工作区 |
| Mod+Ctrl+1~9 | 移动列到工作区 |

## 截图

| 快捷键 | 功能 |
|--------|------|
| Print / Mod+Alt+A | 区域截图 |
| Ctrl+Print | 窗口截图 |
| Shift+Print | 全屏截图 |
| Mod+Shift+S | satty 编辑 |

## 系统

| 快捷键 | 功能 |
|--------|------|
| Mod+Shift+E | 退出 niri |
| Mod+Shift+P | 电源菜单 |
| Mod+Alt+L | 锁屏 |
| Mod+Alt+P | 挂起 |
| Mod+O | 总览 |

## Noctalia

| 快捷键 | 功能 |
|--------|------|
| Mod+Alt+W | 壁纸选择 |
| Mod+F10 | 随机壁纸 |
| Mod+Alt+V | 剪贴板历史 |
| Mod+Alt+S | 收起到侧边栏 |
| Mod+F3 | 录屏菜单 |

## 输入法

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Space | 切换输入法 |
| Ctrl+Shift+F | 简繁切换 |
| Ctrl+. | 中英文标点 |
